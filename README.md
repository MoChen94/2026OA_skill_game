# OA协同办公平台

光伏清洁企业的局域网协同办公系统：工单调度、报修审批、设备台账、文件共享、数字孪生对接一体化。

## 功能概览

- **工单管理**：派单 → 接单 → 处理 → 验收全流程，支持附件、Excel 导出、状态实时推送
- **报修管理**：两段式（员工报修 → 调度审核立项）
- **设备台账**：设备档案、保修状态、孪生模型映射
- **保养计划**：周期保养到期自动生成工单
- **文件共享**：公司内文件互传（500MB/文件，带上传进度条）+ 工单附件（新建时即可预上传）
- **审批中心**：请假/领料/采购多级审批流
- **公告通知 / 报表中心 / 数据大屏 / 权限管理（9 模块精细授权）**
- **数字孪生对接**：免鉴权接口（工单下发/同步/回调），见《数字孪生对接文档.md》
- **桌面提醒助手**：免安装 exe，工单事件右下角置顶弹窗，点击直达工单详情

## 快速部署（Windows）

> 除 Python 3.11 外零安装，SQLite 数据库，支持完全离线部署

```
1. git clone 本仓库（或直接拷贝文件夹，删除 .git 和 .gitignore 可选）
2. 双击「安装环境.bat」——自动创建 .venv 并优先用 wheels/ 离线装依赖
3. 双击「start.bat」——服务跑在 http://127.0.0.1:8001，自动打开浏览器
4. 演示账号：admin / dispatcher / engineer1~4，密码均为 123456
```

关闭服务：`stop.bat`。详细说明见[部署文档.md](部署文档.md)。

## 项目结构

```
backend/    FastAPI 后端（SQLAlchemy + SQLite + JWT）
frontend/   Vue3 + Element Plus 前端（无构建，本地 vendor 依赖）
notifier/   桌面提醒助手（纯标准库，PyInstaller 打包）
tests/      pytest 自动化测试（12 项）
wheels/     离线依赖包
```

## 运行测试

```
.venv\Scripts\python.exe -m pytest tests -v
```
