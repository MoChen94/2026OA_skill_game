OA协同办公助手 v14（OATool-Notifier.exe）使用说明
====================================================

【作用】
运行本程序后，即使浏览器关闭、窗口最小化、正在看任何其他页面，
工单有动态时屏幕右下角都会弹出置顶提醒卡片：圆角卡片 + 铃铛徽章 +
倒计时进度条 + 滑入动画，带声音，显示在所有窗口之上，8 秒自动关闭。
只有点击卡片本体才会跳转工单详情；超时自动关闭、点 ✕ 关闭都不会跳转。
不依赖浏览器、Windows 通知设置，也不需要 Python 和源码。

【谁会收到什么提醒（v12 按账号+权限自动切换）】
- 任何账号：派给我的新工单 → "收到新工单"弹窗（蓝色卡片）
- 管理员/调度员（默认）、以及被 OA「权限管理」授予「工单跟踪」
  权限的任何账号（如 engineer1）：与我相关的工单（我派发的、
  我报修立项的、派给我的）在 工程师接单、反馈工单（提交验收）、
  验收通过、验收驳回、取消 时弹窗，标题带工程师姓名
  （如"技术员2 反馈了工单"）；验收通过为绿色卡片，其余为蓝色
- 工程师账号被授予「工单跟踪」后，两种提醒同时生效

【使用步骤（只需首次设置一次）】
方式一（推荐，网页生成免输入配置）：
1. 浏览器登录 OA 系统（用接收工单的账号）
2. 点击右上角铃铛（🔕/🔔）→「生成免输入配置」
3. 输入一次登录密码 → 下载 OA助手.ini
4. 把 ini 文件和 OATool-Notifier.exe 放在同一文件夹
5. 双击 exe 即自动登录，无需再输入任何内容

方式二（exe 内首次输入）：
1. 双击 OATool-Notifier.exe
2. 第一次使用时按提示输入：
   - 服务器地址，如 http://192.168.1.100:8001
   - 你的登录账号、密码
   输入成功后自动记忆（保存为 exe 同目录下的 OA助手.ini）
3. 之后双击 exe 即可直接使用：窗口显示
   "已自动登录：xxx（使用记忆的配置）"，无需再输入任何东西
4. 把窗口最小化（不要关闭），保持程序运行

【服务器地址/账号变了怎么办】
重新在网页上生成一次配置覆盖 ini 文件即可；或运行
OATool-Notifier.exe --reset 后重新输入。

【注意：启动顺序】
助手只提醒"启动之后"发生的变化。测试时请先启动助手、等它显示
"当前待接单 N 张（启动前的工单不再提醒）"之后，再派单/处理工单。

【没收到提醒？按下面排查】
1. 版本对不对？窗口第一行必须是"OA协同办公助手 v14"。
   旧版本（v8 及更早）没有工单跟踪功能；v12 及更早超时自动关闭会误开网页；v13 及更早工单超 100 张后会漏提醒。旧了就重新下载：
   浏览器 Ctrl+F5 强刷后访问 http://服务器IP:8001/downloads/OATool-Notifier.exe
2. 账号对不对？窗口显示"已登录：姓名（角色）"。反馈类提醒需要：
   管理员/调度员角色，或已在权限管理里勾选「工单跟踪」。
3. 有没有跟踪对象？窗口应显示"工单跟踪已开启：正在跟踪 N 张工单"
   （N=0 说明当前没有与你相关的未完结工单，属正常）。
4. 时间对不对？只提醒启动之后的变化（见上）。
5. 窗口开着吗？关闭窗口=停止提醒，最小化即可。
   断电重启后助手不会自己运行！双击「设置助手开机自启.bat」一次即可
   以后来电自动启动。
6. 连的是哪台服务器？首次输入的地址若不对，--reset 重输。

【其他】
- 单独测试弹窗：命令行运行  OATool-Notifier.exe --test
- 想开机自动启动？把 exe 的快捷方式放进
  「Win+R 输入 shell:startup」打开的启动文件夹
- 提示"Windows 已保护你的电脑"（SmartScreen）？
  这是未签名程序的正常提示，点「更多信息 → 仍要运行」即可
- 退出程序：在程序窗口里按 Ctrl+C，或直接关闭窗口

【命令行用法（可选）】
OATool-Notifier.exe http://192.168.1.100:8001 engineer2 123456
