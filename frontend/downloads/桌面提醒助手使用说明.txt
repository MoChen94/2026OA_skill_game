OA协同办公助手 v8（OATool-Notifier.exe）使用说明
====================================================

【作用】
- 工程师账号登录：工单指派给你时弹窗提醒，点击卡片自动打开浏览器直达该工单详情
- 管理员/调度员账号登录：自动切换管理模式——与你相关的工单（含你自己派发的，
  无论谁创建）在
  工程师接单、反馈工单（提交验收）、验收通过、验收驳回、取消时弹窗提醒，
  标题带工程师姓名（如"技术员2 反馈了工单"）
  （验收通过为绿色卡片，其余为蓝色），点击卡片同样直达工单详情

工程师电脑上运行本程序后，即使浏览器关闭、窗口最小化、正在看任何
其他页面，只要服务器上**把工单指派给你**，屏幕
右下角就会弹出置顶提醒卡片：圆角卡片 + 铃铛徽章 + 倒计时进度条 +
滑入动画，带声音，显示在所有窗口之上，8 秒自动关闭（点击任意处可
提前关闭）。卡片为品牌蓝。
只有被指派者本人会收到提醒，派发者和其他人不会收到。
不依赖浏览器、Windows 通知设置，也不需要 Python 和源码。

【使用步骤（v8 起只需首次设置一次）】
方式一（推荐，网页生成免输入配置）：
1. 浏览器登录 OA 系统（用接收工单的工程师账号）
2. 点击右上角铃铛（🔕/🔔）→「生成免输入配置」
3. 输入一次登录密码 → 下载 OA助手.ini
4. 把 ini 文件和 OATool-Notifier.exe 放在同一文件夹
5. 双击 exe 即自动登录，无需再输入任何内容

方式二（exe 内首次输入）：
1. 双击 OATool-Notifier.exe
2. 第一次使用时按提示输入：
   - 服务器地址，如 http://192.168.1.100:8001
   - 你的登录账号（接收工单的工程师账号，如 engineer2）
   - 登录密码
   输入成功后自动记忆（保存为 exe 同目录下的 OA助手.ini）
3. 之后双击 exe 即可直接使用：窗口显示
   "已自动登录：xxx（使用记忆的配置）"，无需再输入任何东西
4. 把窗口最小化（不要关闭），派给你的新工单就会弹提醒

【服务器地址/账号变了怎么办】
重新在网页上生成一次配置覆盖 ini 文件即可；或运行
OATool-Notifier.exe --reset 后重新输入。

【换账号 / 清除记忆配置】
命令行运行：OATool-Notifier.exe --reset
然后重新双击输入新的账号密码即可。

【注意：启动顺序】
助手只提醒"启动之后"新派的工单。测试时请先启动助手、
等它显示"请派一张新工单测试"之后，再去派单。

【为什么之前没提醒？按下面排查】
1. 账号对不对？窗口会显示"已登录：姓名（角色）"。
   演示账号里 engineer1 实际是调度员角色，只有把工单直接指派给该
   账号才会提醒；请用真正接收工单的工程师账号登录。
2. 时间对不对？助手只提醒启动之后新派的工单（见上）。
3. 右下角弹窗有没有？v6 的置顶弹窗不依赖 Windows 通知设置，
   任何页面都能看到。若连它都不出现，说明程序没在监听：
   检查窗口是否被关闭、服务器是否在运行。

【其他】
- 单独测试弹窗：命令行运行  OATool-Notifier.exe --test
- 想自动启动？把 exe 的快捷方式放进「Win+R 输入 shell:startup」打开的启动文件夹
- 提示"Windows 已保护你的电脑"（SmartScreen）？
  这是未签名程序的正常提示，点「更多信息 → 仍要运行」即可
- 退出程序：在程序窗口里按 Ctrl+C，或直接关闭窗口

【命令行用法（可选）】
OATool-Notifier.exe http://192.168.1.100:8001 engineer2 123456
